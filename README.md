# Bootstrap Registration Webpage

## Overview

This project is a responsive webpage built using Bootstrap 5. It includes:

* A responsive navigation bar
* A registration form
* A responsive table displaying sample user data
* Responsive images
* Bootstrap buttons with responsive utility classes

## Files

* `index.html` - Main webpage
* `style.css` - Custom styles
* `README.md` - Project instructions

## Viewing the Project

1. Download or clone the project files.
2. Make sure the following files are in the same folder:

   * `index.html`
   * `style.css`
3. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, or Safari).
4. An internet connection is required because Bootstrap is loaded using the Bootstrap CDN.

## Features

* Responsive Bootstrap navigation bar
* Registration form with required fields
* Responsive Bootstrap table
* Responsive images
* Buttons using Bootstrap utility classes
* Mobile-friendly layout
